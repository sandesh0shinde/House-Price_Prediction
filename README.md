# House-Price_Prediction
## About the Project
This project uses Machine Learning to predict house values using the California Housing dataset. It was developed using Python and Scikit-learn in Google Colab.
The goal of this project is to understand the basic Machine Learning workflow, from exploring a dataset to training and evaluating a model.

## Objectives
- Understand and explore a real-world housing dataset.
- Prepare data for Machine Learning.
- Train a regression model to predict house values.
- Evaluate the model using standard performance metrics.
- Visualize actual and predicted values.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
This project uses the California Housing dataset available through Scikit-learn.
The dataset contains information about California districts, including median income, housing age, average rooms, population, and other features.

Note: The dataset represents historical district-level data. Predictions are educational estimates, not current property valuations.

## Machine Learning Model
The project uses a Random Forest Regressor to predict housing values.

The workflow includes:
- Loading the dataset.
- Exploring and visualizing the data.
- Splitting the data into training and testing sets.
- Training the model.
- Generating predictions.
- Evaluating model performance using MAE, RMSE, and R².
- Comparing actual values with predicted values.

## How to Run the Project
- Open the notebook file house_price_prediction_colab.ipynb.
- Open Google Colab.
- Upload the notebook using File → Upload notebook.
- Run the cells in order using Runtime → Run all.
- Review the evaluation metrics and visualizations. 

An internet connection is needed to load the dataset the first time.

## Results
The model's performance is evaluated using:
- MAE: Mean Absolute Error
- RMSE: Root Mean Squared Error
- R² Score: Measures how well the model explains variation in the target values
